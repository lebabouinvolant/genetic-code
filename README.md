# Genetic Code
Ce repo contient mes premières expérimentations autour de 2 champs du machine learning: les algorithms génétiques et les réseaux de neurones.  
Pour commencer ces projets, j'ai utilisé comme ressource le livre [The Nature of Code](https://natureofcode.com/) de Daniel Shiffman, et plus particulièrement les chapitres 9, 10 et 11, et ses tutoriels sur l'implémentation d'un réseau de neurone manuellement (mais pas tout, j'ai designé moi même certains éléments).  
Note: Les blocs de base de ce projet sont toutes présentes from scratch, mais j'utilise parfois des versions plus efficientes et non codée par moi dans des scripts ultérieurs à celui où l'implémentation from scratch est présente (genre les matrices et numpy)  
  
Ce projet utilise Python 3.14 et les librairies standard (pygames en est une je crois)
