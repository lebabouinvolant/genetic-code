# Genetic Code
Ce repo contient mes premières expérimentations autour de 2 champs du machine learning: les algorithms génétiques et les réseaux de neurones
Pour commencer ces projets, j'ai utilisé comme ressource le livre [The Nature of Code](https://natureofcode.com/) de Daniel Shiffman, et plus particulièrement les chapitres 9, 10 et 11.
